# Single-Cell RNA-seq PBMC Analysis

A single-cell RNA-seq analysis of human peripheral blood mononuclear cells (PBMCs) using the 10x Genomics PBMC 3K dataset.

The project follows the analysis from a Cell Ranger gene-barcode count matrix through quality control, preprocessing, dimensionality reduction, clustering, marker identification, and cell-type annotation.

## Dataset

* Dataset: 10x Genomics PBMC 3K
* Cells: 2,700
* Features: 32,738 genes
* Input: Cell Ranger filtered gene-barcode matrix

## Project Structure

* `data/` — input data
* `scripts/` — analysis scripts
* `results/` — analysis outputs and figures
* `docs/` — project documentation

Raw sequencing/count data are not tracked in Git.

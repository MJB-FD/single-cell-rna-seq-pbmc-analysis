# Cell Type Annotation

## Overview

Cell types were assigned manually after unsupervised clustering using a
combination of canonical PBMC marker genes and cluster-specific markers
identified with Seurat's `FindAllMarkers()` function.

Cluster numbers generated by Seurat are arbitrary and do not represent
biological identities. Each cluster was therefore evaluated based on its
gene-expression profile before a cell-type label was assigned.

## Cluster Annotations

| Cluster | Cell type | Supporting markers |
|---------|-----------|--------------------|
| 0 | Naive T cells | CCR7, LEF1, TCF7, CD3D, CD3E |
| 1 | Classical monocytes | CD14, S100A8, S100A9, FCN1 |
| 2 | IL7R+ CD4 T cells | IL7R, CD40LG, CD3D, CD3E, GIMAP7 |
| 3 | B cells | CD79A, MS4A1 |
| 4 | Cytotoxic CD8 T cells | CD8A, CD3D, CCL5, GZMK, PRF1 |
| 5 | FCGR3A+ monocytes | FCGR3A, MS4A7, LST1 |
| 6 | NK cells | GNLY, KLRD1, FGFBP2, NKG7, GZMB |
| 7 | CD1C+ dendritic cells | CD1C, FCER1A, CLEC10A |
| 8 | Platelets | PF4, GP9, ITGA2B, GP1BA |

## Annotation Strategy

Canonical marker expression was first visualized across clusters using a
DotPlot. Broad cell populations were identified from combinations of known
lineage markers rather than from individual genes.

Cluster-specific differential expression results were then examined to
refine the annotations. Marker genes were evaluated using average log2 fold
change and the proportion of cells expressing each gene inside (`pct.1`) and
outside (`pct.2`) the cluster.

For example, clusters 1 and 5 both showed a monocyte/myeloid expression
program but differed in their strongest markers. Cluster 1 showed enrichment
of CD14, S100A8, S100A9, and FCN1, supporting a classical monocyte identity.
Cluster 5 showed strong FCGR3A and MS4A7 expression, supporting an FCGR3A+
monocyte identity.

Similarly, clusters 4 and 6 both expressed cytotoxic genes such as NKG7 and
PRF1. Cluster 4 also expressed T-cell markers including CD3D and CD8A,
supporting a cytotoxic CD8 T-cell identity. Cluster 6 instead showed strong
GNLY, KLRD1, FGFBP2, and GZMB expression, supporting an NK-cell identity.

## Interpretation Note

Statistical significance alone was not used to assign cell identities.
Some highly significant genes, particularly ribosomal genes, were expressed
in nearly all cells and provided little information about cell type.

Marker specificity, effect size, expression frequency, and known biological
function were considered together when interpreting each cluster.
